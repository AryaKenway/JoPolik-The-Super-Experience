# JoPolik-The Super Experience

This project is a hybrid 2D-3D educational game built in Unity, combining platforming, exploration, and problem-solving. 

The first level features a 2D platformer with animations, surface effectors, and NPC interactions, ending with a DSA challenge that unlocks progression. 
The second level shifts into a 3D apartment environment, surrounded by procedurally generated worlds, where players solve another DSA question to earn rewards.
Multiplayer functionality is powered by Photon PUN, enabling seamless real-time interaction and cooperative play.
